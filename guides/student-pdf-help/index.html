Student PDF workflow

  1. Start with clear pages — retake blurred photos before making the PDF.
  2. Convert images into PDF if your notes or assignment pages are photos.
  3. Merge related files if you have forms, certificates, reports, or supporting documents.
  4. Reorder pages so the file follows the required submission order.
  5. Delete unnecessary pages like duplicates, blanks, rough pages, or old drafts.
  6. Crop margins so the content looks clean and readable.
  7. Rotate sideways pages before uploading.
  8. Compress the final PDF and check readability before submission.

Final checklist before uploading student PDFs

  • Name, roll number, student ID, course details, and dates are readable.
  • Pages are in correct order.
  • No blank, duplicate, blurred, or rough pages.
  • No sideways pages.
  • Handwriting, diagrams, formulas, tables, and signatures are clear.
  • File size is below the upload limit.
  • Filename is simple, for example: assignment-final.pdf.
